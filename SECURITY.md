# Security policy

## Reporting a vulnerability

Please report security issues privately, through GitHub's private vulnerability reporting:
open the affected repository's **Security** tab and choose **Report a vulnerability**. Do not
open a public issue.

Include what is affected, how to reproduce it, and its impact as you understand it. You will
get an acknowledgement, and a fix or a plan, as soon as the maintainers can provide one; the
issue is disclosed publicly once a fix is released.

## Supported versions

densa is at 0.x: only the latest release (and the `main` branch) receives fixes.
